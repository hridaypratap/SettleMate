# SettleMate

A full-stack MERN application for splitting group expenses, calculating balances, and simplifying debts.

## Tech Stack

### Frontend
- React
- Vite
- JavaScript

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Zod

### AI
- Google Gemini API
- AI-powered receipt extraction

### DevOps
- Docker
- Git
- GitHub
- GitHub Actions
